README — Portfolio “from scratch” (HTML • CSS • JS)
Objectif : un portfolio rapide, accessible, SEO-friendly, sans framework, codé à la main.
Fonctionnalités clés
Pages statiques HTML5 sémantique (SEO + accessibilité).
CSS responsive (mobile-first), thèmes clair/sombre (prefers-color-scheme).
JS vanilla modulaire (navigation, animations douces, formulaire).
Performance : images optimisées, lazy-loading, Police système par défaut.
Accessibilité : focus visible, ARIA minimal, contrastes AA.
Déploiement simple (GitHub Pages).
